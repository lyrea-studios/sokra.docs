Sokra has four workspace modes. Mode shapes the terms, starting settings, and learning focus you see. It is separate from each person's role and access.

| Mode | Use it for | Terms you may see |
| --- | --- | --- |
| [School](../../modes/school/) | Classroom teaching and student practice | Curriculum, learning goal, activity, mastery |
| [Enterprise](../../modes/enterprise/) | Workplace training and team development | Skill map, competency, training module, readiness |
| [Higher Education](../../modes/higher-education/) | Courses, seminars, and academic work | Syllabus, learning objective, module, proficiency |
| [Workspace](../../modes/personal/) | Self-directed learning and personal practice | Learning map, goal, activity, progress |

**Workspace** is the personal mode's label. All four modes still use a workspace to hold their content.

## Set or change the mode

Workspace owners and admins can change it:

1. Select the workspace you want to manage.
2. Open its **General** settings.
3. Choose **Organization mode**.
4. Review the use cases shown for that mode and select any that fit.
5. Save the settings and check the result.

If the controls are disabled, ask an owner or admin. Changing the mode does not grant new management rights.

## Choose use cases

Mode answers “What setting is this for?” Use cases answer “What do we want to do here?” You can select more than one, such as employee onboarding and skill development.

Use cases help emphasize relevant workflows, templates, and starting settings. They do not grant access or hide features. Leaving the selection empty keeps the mode's default setup.

## What happens to existing work?

Mode changes affect future defaults. Existing published activities keep the behavior of the version that was published. Do not expect a mode switch to rewrite past learning records or work already in progress.

Before publishing new work, review its goals, source material, support, and completion settings. A mode supplies a starting point; it does not replace your judgment.

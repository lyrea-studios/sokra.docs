Owners and admins manage people in **People** in the sidebar. The page has the tabs **Members** and **Groups**.

## Invite people

Select **Invite members**, then choose:

- **Invite by email:** invite colleagues as members or owners. New owners must be invited by email.
- **Invite by link:** share an invite link for new members. Links cannot add owners.

The invited person opens the invite with the intended account; see [Sign in to Klarisma](../../start/sign-in/).

## Create member accounts

**Create member accounts** creates accounts without email. Enter how many accounts you need and, if you like, one name per line. Klarisma creates a username and a one-time setup code for each person. The person uses the code to choose their own password; nobody else sees it. The code works once and for 72 hours. Use **Print login cards** to hand out the codes.

## Set a workspace role

Change the role in the person's row: **Organization owner**, **Organization admin**, or **Member**. See [Roles and access](../roles-and-access/) for what each role can do.

## Create a space and add members

1. Select **+** next to the list of spaces in the sidebar. Give the space a clear name, such as the team or cohort, and choose who can see it.
2. Open the space and select **Members**, then **Add members** › **Add from organization**.
3. Search for the person, choose the role **Member** for learners or **Admin** for the trainer, and select **Add to space**.

A shared link alone does not grant access. People need to be members of the space.

## Pseudonyms

Each person has a pseudonym in **People**, for example `L-ABC12`. Use it when you discuss learning results without names.

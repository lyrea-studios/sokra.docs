---
title: Assign an activity
description: Choose who can start an activity, when it is available, and which version they use.
---
You need a published activity and access to assign work in the target space.

## Set up the assignment

Open the activity's assignment action, then work through the steps:

1. **Audience:** Choose the space or spaces and who the assignment is for. Check any selected groups or learners.
2. **Availability:** Set the start, close, and due dates if needed. Check what happens to work already in progress after the activity closes.
3. **Version:** Check which published version learners will use.
4. **Participation:** Choose from the modes offered for this activity.
5. **Personalization:** Review the learning and support settings offered.
6. **Review:** Check the full summary, then confirm the assignment.

## Choose a version policy

**Pin this version** keeps the assignment on the chosen version even if you publish changes later.

**Use future updates** lets new learning runs use later published versions. Work already in progress stays on the version it started with.

## Check the result

Open the target space and check that the activity is listed. Learners need the right access and must be within the assignment's availability window to start.

Share the assigned activity link from the space. A link to an activity in the authoring library may open a preview or ask the user to choose a space.

Owners and admins use **Materials** in the sidebar to find and organize files for the workspace. If you manage a space, use its **Materials** tab instead. The files you can see depend on the workspace and your access.

## Add a file

1. Select **Materials** in the sidebar, or the **Materials** tab in your space.
2. Open the collection where you want to keep the file, or stay at the top level.
3. Select **Upload** and choose your file.
4. Keep the page open while the upload runs. Check the file's status when it finishes.

<ProductScreenshot src={materialsLibrary} alt="Materials collection with two uploaded text files that are ready." caption="A collection with uploaded files. Ready means activities can use the file." />

The upload control shows which files it accepts. If a file is rejected, use the message shown to check its type or size.

## Check readiness

A file can finish uploading while its content is still being prepared. Its status shows **Content processing** until it reads **Content ready**. Wait for that before relying on it as an activity source. If the status shows that content is unavailable, follow the message shown for that file.

## Use clear names

Choose file and collection names that tell you what is inside, such as “River fieldwork — source texts.” Select **New collection**, enter a name, then select **Create** to group related materials.

<ProductScreenshot src={newCollection} alt="New collection dialog with a sample collection name." caption="Name the collection, then select Create. The dialog was cancelled for this screenshot." />

Before using a file in an activity, open it and check that it is the right version.

Adding a file to Materials does not by itself assign a learning activity to a group.
